# YumeShelf 0.3.0-preview.1 测试包说明

本包面向Windows 10/11 x64，包含.NET 8桌面运行时，无需安装SDK或另装.NET。当前是未签名测试包，不是正式发行版；不同机器、DPI、输入法及安全软件兼容性仍待人工验收。不要把自检成功等同于干净系统验收。

## 使用与安装

1. 核对随包提供的ZIP SHA-256，解压完整文件夹到可写目录，不要只复制EXE或在压缩包里运行。
2. 直接运行`YumeShelf.exe`即可使用。不要同时运行不同版本；应用有单实例保护。
3. 可选安装：在解压目录用PowerShell运行`powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1`。脚本仅对本次进程设置执行策略，不修改系统默认策略；它校验包中文件哈希，复制到`%LOCALAPPDATA%\Programs\YumeShelf\0.3.0-preview.1`，创建桌面快捷方式，无需管理员。也可以完全不运行脚本，直接使用解压版。
4. 首次使用在设置中填写兼容API地址、Key、文字/视觉模型。Key和会话均使用当前Windows用户加密，包内不含开发者的用户数据或凭据。

## 升级、回退和卸载

- 升级前正常关闭旧程序，先备份`%LOCALAPPDATA%\YumeShelf`。新版解压到新目录/按版本安装，库和设置继续读取原数据目录。安装脚本遇到相同版本目录会拒绝覆盖；新版本可以并排保留，桌面快捷方式指向新安装的版本。
- 本版新增`settings.yume-session`保存最近40条文字消息、最多6轮有限上下文和输入草稿。正常结束请求与关闭时保存；崩溃中途未保存部分可能丢失。历史消息不等于最新库事实；图片、来源卡、修改/扫描/文档草稿与撤销不跨重启恢复。有待确认任务时不恢复模型上下文。
- 回退时正常关闭新版，从保留的旧目录启动；旧版忽略新增会话文件。先验证测试库，不直接对唯一一份正式库做跨版本回退实验。
- 卸载解压版：关闭应用后删除解压文件夹。按版本安装的：删除对应的`%LOCALAPPDATA%\Programs\YumeShelf\版本号`文件夹及不再使用的桌面快捷方式。不会自动删除`%LOCALAPPDATA%\YumeShelf`或游戏本体；彻底清除个人数据需自行备份并明确选择删除该数据目录。
- 本版没有注册系统卸载器或自动更新，也未提供签名安装向导。清理旧版本之前确认不再需要回退。遇到安全软件拦截请记录现象，不建议关闭防护绕过。

## 开发者构建与验证

先运行`scripts/check.ps1`，再运行`scripts/package.ps1`。后者生成自包含目录、ZIP、SHA-256及`package-manifest.json`，写明源提交和工作区是否有未提交内容。对发布目录执行`YumeShelf.exe --verify-package 报告绝对路径`可进行不读取用户库/配置的资源与运行时检查；不是完整UI测试。

真实AI按根目录`YumeTestV1.md`进行，记录包清单中的提交号。首版放行前仍需：干净Win10/Win11、100/125/150/200%缩放、安装/升级/回退/卸载、断网与磁盘权限、真实文字/视觉/工具模型场景。未通过项不宣称兼容。
